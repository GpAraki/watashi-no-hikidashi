One drawer

入れる、見える、
片づく。

タスクを入れる場所はひとつ。メニューバーのポップオーバー、一覧ウィンドウ、ウィジェット、そして Claude が、同じ引き出しを開け閉めします。

01
add_circle

思いついたら、すぐ入れる

メニューバーのクイック入力、⌘N の追加シート、どのアプリからでもテキストを選択して右クリック →「引き出しにタスクを追加」。1 行目がタイトル、残りがメモになります。

02
event_available

タイプを選ぶと、期限が決まる

「今日」は今日の終わり、「スプリント」は今のスプリントの最終日、「期限あり」は日付指定、「いつか」は期限なし。約束の強さで分けるから、並べ替えに迷いません。

03
history

誰が何をしたか、残る

人・ウィジェット・AI のどれが変更したかを操作履歴に記録。AI が勝手に変えたものも一覧で確認でき、その場で取り消せます。削除はすべて論理削除です。

Main window

一覧と編集を、ひとつの画面で。

  • 1一覧と検索未完了・完了済み・アーカイブを切り替え、タイトルとメモで検索
  • 2自動保存の編集フォームタイプ、状態、優先度、期限。入力が止まれば保存
  • 3リンクとコメントNotion や Jira へのリンクをまとめ、AI との会話を残す

Desktop widget

3 つのサイズ、
同じ引き出し。

今日の進捗と期限を確認し、その場で完了チェック。行の丸で完了、タイトルで本体の該当タスクを開きます。本体が書き込めば数百ミリ秒で描き直されます。

SMALL今日の進捗と次のタスク

進捗バーと次にやること。期限ありのタスクには日付を添えます。

MEDIUM今日と近い期限

今日のタスクと近い期限の未完了を 3 件まで。収まらない分は「すべて表示」から。

LARGEスプリントを含めた見通し

今日・期限あり・スプリントの全セクションを 7 件まで。「いつか」は件数だけ。

Works with Claude

AI に任せても、
手綱はあなたの手に。

アプリの中に LLM はありません。MCP サーバーとしてタスク操作を公開し、Claude Code や Claude Desktop から呼び出します。

terminalMCP TOOLS

読む、足す、片づける

一覧、追加、更新、完了、アーカイブ、プロジェクト一覧、コメント。会議の議事録から「今日やること」を起こす、といった使い方ができます。

  • list_tasks
  • create_task
  • update_task
  • complete_task
  • archive_task
forumCOMMENTS

状況はコメントで届く

AI が進めた作業の報告は、タスクのコメントとして残ります。本体のスレッドで読み、必要なら返事を書けます。

  • 人と AI の両方が書ける
  • タスクごとのスレッド
  • 削除も取り消せる
undoUNDO

AI の変更は、ぜんぶ取り消せる

AI が作ったタスクには印が付き、変更は差分つきで操作履歴に残ります。やりすぎたら履歴から戻す。物理削除は AI に公開していません。

  • actor = ai の記録
  • 差分つきの履歴
  • ワンクリックで取り消し

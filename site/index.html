引き出しにタスクを追加

01

思いついたら、
その場で入れる

どのアプリを使っていても、⌃⌥Space で入力パネルが浮かび、Return で追加して閉じます。作業中のアプリはそのまま。メールやチャットの文字を選んで右クリック →「引き出しにタスクを追加」でも入れられます。1 行目がタイトル、残りがメモ、URL はリンクになります。マイクのボタンを押せば、話して入れることもできます(音声は Mac の中だけで文字にします)。

02

デスクトップで
次のタスクがわかる

ウィジェットは small / medium / large の 3 サイズ。今日の進捗と期限をいつも見えるところに置いて、行の丸をクリックすればその場で完了。本体や Claude が書き込むと、数百ミリ秒でウィジェットが描き直されます。Notion や Jira のリンクもウィジェットから直接開けます。

03

進んだことを
コメントで積み上げる

タスクには、あなたも Claude もコメントを残せます。「日報」に切り替えると、全タスクのコメントと完了が日付ごとに並び、直近 7 / 14 / 30 日を Markdown でコピーして、そのまま日報や週報に貼れます。

04

整理は Claude に。
決めるのは、自分で。

アプリの中に AI はいません。MCP サーバーとしてタスクの操作を公開し、Claude Code や Claude Desktop から呼び出します。Jira の課題を閉じたら対応するタスクも完了に、といった連携もできます。Claude が変えたところは操作履歴に差分つきで残るので、気に入らなければワンクリックで戻せます。

4 つのタイプ

Task types

タスクには 4 つのタイプがあり、選ぶと期限が決まります。毎回日付を入れなくてよく、何から手をつけるかは並び順を見ればわかります。

light_mode

Type 1

今日

今日の終わりまで

今日中に終えること。ウィジェットのいちばん上に、進捗バーと一緒に出ます。

event

Type 2

期限あり

日付と時刻を指定

締め切りがあること。「あと 2 日」「期限切れ」のバッジで迫り具合が分かります。

flag

Type 3

スプリント

今のスプリントの最終日まで

今週中くらいに終えること。区切りは水曜開始の 1 週間が既定で、変えられます。

inbox

Type 4

いつか

期限なし

いつかやること。ウィジェットでは件数だけを控えめに出します。

Features

task_alt

丸で完了

ウィジェットの行の丸をクリックするとその場で完了。タイトルをクリックすると本体で開きます。

すぐ反映

本体や Claude が書き込むと、数百ミリ秒でウィジェットが描き直されます。

link

リンクもウィジェットから

Notion や Jira のリンクが付いたタスクは、ウィジェットから直接開けます。

notifications_active

決まった時刻に通知

平日の 9:30 と 17:30 など、決めた時刻に「タスクを見直しましょう」と通知します。通知から更新用の指示をコピーして、Claude に貼れます。

schedule

自動で更新(任意)

同じ時刻に Claude Code を裏で動かし、Jira の状態を見てタスクを揃える設定も、コマンドひとつで登録できます。

undo

あとから取り消せる

Claude の変更は操作履歴に差分つきで残り、ワンクリックで戻せます。削除は論理削除なので、消えてなくなることはありません。

よくあるご質問

FAQ

質問するarrow_forward
Q.1データはどこに保存されますか?
Mac のローカルにある SQLite のデータベースに保存されます。外部のサーバーには送信しません。
Q.2Claude がなくても使えますか?
使えます。Claude との連携は任意で、ウィジェット・入力パネル・日報はアプリだけで動きます。
Q.3動作環境を教えてください
macOS 14 Sonoma 以降、Apple Silicon と Intel の両方(Universal)で動きます。Developer ID で署名し、Apple の公証を通しています。
Q.4Claude からつながりません
ダウンロードフォルダのまま開くと、macOS がアプリを一時的な場所に移して起動するため、MCP サーバーのパスが変わってしまいます。Hikidashi.app を「アプリケーション」フォルダへ移してから開き直してください。
Q.5アップデートはどうすればいいですか?
新しい Hikidashi.app に入れ替えて起動するだけです。データは引き継がれます。入れ替えたあとウィジェットが空のままのときは、pluginkit -a /Applications/Hikidashi.app/Contents/PlugIns/TaskWidget.appex && killall chronod で復帰します。
Q.6Claude の変更を元に戻せますか?
はい。Claude の変更はすべて操作履歴に差分つきで残り、アプリからワンクリックで取り消せます。削除はすべて論理削除なので、消えてなくなることはありません。
Q.7料金はかかりますか?
無料です。MIT ライセンスで配布しています。
